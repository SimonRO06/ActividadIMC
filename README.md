🧮 Calculadora de IMC
Esta es una aplicación web simple desarrollada en HTML y CSS que permite calcular el Índice de Masa Corporal (IMC) a partir de los datos ingresados por el usuario.


📋 Funcionalidades
Recoge datos del usuario:

Edad

Nombre

Peso (en kg)

Estatura (en metros)

Botón Enviar para procesar la información (lógica por implementar en JS).

Botón Eliminar para limpiar los campos del formulario.

Diseño estilizado con bordes redondeados, botones con estilos diferenciados y disposición clara de los campos.

🛠️ Tecnologías utilizadas

HTML5: Estructura del formulario.

CSS3: Estilos visuales (botones, bordes, espaciado).

JS: Funciones de recopilacion de la informacion.

🧠 Posibles mejoras
Añadir funcionalidad en JavaScript para:

Calcular automáticamente el IMC.

Mostrar un mensaje personalizado con el resultado.

Validar que los campos estén correctamente llenos antes de enviar.

Agregar un sistema de clasificación (peso bajo, normal, sobrepeso, obesidad).

Hacer la página responsive para dispositivos móviles.

✍️ Cómo usar
Abre el archivo HTML en tu navegador.

Llena los campos con tu información.

Presiona Enviar (si se implementa JS, calculará el IMC).

Presiona Eliminar para limpiar los campos.
